FAQ essencial (modo offline)

O anexo não foi analisado? Confira o chip: ✓ N caracteres lidos significa que o texto chegou ao modelo. Com ⚠, converta para TXT/CSV, PDF com texto ou envie uma imagem.

Vídeo não abre? Converta para MP4/H.264. MKV, AVI e codecs raros não são decodificados pelo navegador; capturas PNG/JPG funcionam sempre.

Limites: 1 GiB por arquivo lógico (partes de 48 MiB), 5 arquivos por mensagem e 3 imagens/fotogramas por requisição.

Histórico sumiu? As conversas são isoladas por uma identidade anônima neste navegador. Limpar dados do site gera outra identidade.
